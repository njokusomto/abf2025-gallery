## Choosing the Right Name

### Consider These Factors:

1. **Domain Availability**
   - Check if `.com` or subdomain is available
   - Consider using `gallery.dominioncity.org` if you have the main domain

2. **Ease of Remembering**
   - Can people remember it after hearing it once?
   - Is it easy to spell?

3. **Church Branding**
   - Does it align with your existing branding?
   - Does it match your church's tone and style?

4. **Expandability**
   - Could you use this name for other events beyond Sundays?
   - Does it limit you to just photos, or could you add videos later?

5. **SEO Considerations**
   - Including "Dominion City" helps with local search
   - Adding "church" or "photos" helps people find you

---

## Subdomain Strategy (Recommended)

If your church already owns `dominioncity.org` or similar, use a subdomain:

- `gallery.dominioncity.org`
- `photos.dominioncity.org`
- `moments.dominioncity.org`
- `sundays.dominioncity.org`

**Benefits:**
- Keeps branding consistent
- No need to buy new domain
- Better SEO (links to main church site)
- Professional appearance

## Implementation in Code

Once you choose a name, update it in:

1. **Page title** (`pages/index.tsx`):
   ```tsx
   <title>Dominion Moments - Sunday Service Photos</title>
   ```

2. **Meta tags**:
   ```tsx
   <meta property="og:title" content="Dominion Moments" />
   ```

3. **Hero heading**:
   ```tsx
   <h1>Dominion Moments</h1>
   ```

4. **Vercel project name** when deploying
